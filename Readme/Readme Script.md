🛍️ Customer Shopping Behavior Analysis
📌 Project Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across multiple product categories.
The main objective is to uncover insights related to:

🧑‍🤝‍🧑 Customer demographics
💰 Spending patterns
🛒 Product preferences
🎟️ Discount usage
⭐ Customer reviews
📦 Shipping & subscription behavior
The project combines Python, MySQL, and Power BI to perform data cleaning, analysis, and visualization for business decision-making.

🧹 Data Cleaning & Preprocessing (Python)

Generated summary statistics using describe()
Handled missing values in Review Rating
Standardized column names into snake_case
Created new features:
    👥 age_group
    📅 purchase_frequency_days
Removed redundant columns
Loaded cleaned data into MySQL for SQL analysis
